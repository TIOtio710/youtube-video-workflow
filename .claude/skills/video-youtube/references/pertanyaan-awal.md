# Kartu pertanyaan awal

Ajukan dalam **satu** kartu (AskUserQuestion, maksimal 4 pertanyaan per kartu, dua kartu kalau perlu). Jangan bertanya lagi di tengah jalan kecuali ada yang benar-benar menghalangi.

1. **Topik + video referensi.** Topik, target penonton, hasil yang didapat penonton di akhir video, dan link video referensi. Kalau tidak ada referensi, tawarkan mencarikan (utamakan kreator USA, lalu Eropa).
2. **Maksud video / CTA.** Tutorial murni, atau tutorial dengan upsell (produk, webinar, komunitas)? Kalau upsell, minta link landing page sebagai sumber klaim.
3. **Presenter dan biaya HeyGen.** Look avatar mana, avatar hanya di pembuka (dan penutup) atau juga di transisi antar bab, dan batas kredit untuk run ini. Sebutkan perkiraan dari [biaya-heygen.md](biaya-heygen.md).
4. **Caption dan musik.** Caption burned-in, musik latar, keduanya, atau tidak sama sekali.
5. **Rekaman alur produk asli** (opsional, tapi paling menaikkan akurasi). Rekaman layar 2–3 menit atau 5–10 screenshot alur yang akan didemokan. Tanpa ini, mockup dibangun dari teks docs dan harus dicek user di akhir.

Catat semua jawaban dan default yang kamu ambil di `brief.md`. Untuk mode ditinggal: tahan komputer tetap menyala (keep-awake) dan ingatkan user untuk tidak menutup lid.
